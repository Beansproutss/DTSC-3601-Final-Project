# DTSC-3601-Final-Project (NoParking)
Final project repository for DTSC 3601

Our project provides long term prediction of Charlotte traffic patterns surrounding the UNC Charlotte campus, based on historical data. It is primarily intended to benefit those who frequently drive to and from campus, but at different times (like students), so that they can plan their routes ahead of time.

## Installation/Access
```bash
$ pip install NoParking 
```
We recommend the following libraries with their minimum versions: NumPy 1.21.0, scikit-learn 1.0.0, statsmodels 0.13.0, SciPy 1.10.0, Matplotlib 3.7.0, and Pandas 1.5.0. These will be necessary to accurately predict traffic patterns at certain parts of the day.
An environment setup will look like this:
pip install numpy>=1.21.0
pip install scikit-learn>=1.0.0
pip install statsmodels>=0.13.0
pip install scipy>=1.10.0
pip install pandas>=1.5.0
pip install matplotlib>=3.7.0

## Usage
"NoParking" can be used for long-term prediction of traffic surrounding the UNC Charlotte campus (up to a week out) for different days/times.
Users will be able to input a time/day, and our model will output a map of what traffic should look like. Roads highlighted in green will show a mostly clear road, orange will show slight traffic, and red will indicate heavy traffic. Using this output, users will be able to plan efficient paths to their destination.
